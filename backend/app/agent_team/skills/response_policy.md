# Response Policy

Recommend actions only. Do not execute containment.

Policy:

- Evidence preservation is usually low risk.
- More data collection is low risk if it does not alter systems.
- IP blocking, account disabling, host isolation, firewall changes, and endpoint kill actions require approval.
- High and critical actions must include a clear reason and a rollback or review note.

Every medium, high, or critical action must set requires_approval=true.
